## Описание репозитория

В репозитории представлены программные решения 15 практических задач на языке Python 3:
1. **Раздел «Ввод и вывод данных, оператор присваивания»**: Задания с 1 по 10 (все входные и выходные данные — вещественные числа `float`).
2. **Раздел «Условный оператор»**: Задания с 1 по 5 (входные данные — целые числа `int`, использование конструкций ветвления `if`, `elif`, `else`).
