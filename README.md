## Описание

В репозитории представлены программные решения 15 практических задач на языке Python 3:
1. **Раздел «Ввод и вывод данных, оператор присваивания»**: Задания с 1 по 10 (`io1.py` - `io10.py`). Все входные и выходные данные — вещественные числа (`float`).
2. **Раздел «Условный оператор»**: Задания с 1 по 5 (`if1.py` - `if5.py`). Все числа целые (`int`), конструкции ветвления `if`, `elif`, `else`.

Все программы написаны лаконично, в академическом стиле без избыточных текстовых приглашений ко вводу.
